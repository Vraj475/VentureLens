# VentureLens — AI-Powered Business Idea Validation Platform

## Overview

VentureLens is a full-stack MERN application that validates business ideas using a multi-step pipeline: structured idea extraction → guided interview → RAG-based knowledge retrieval → live web research → multi-dimensional AI analysis → devil's advocate challenge → shareable markdown report. The goal is a simple, accurate, and polished product with zero scope creep.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite, React Router DOM v6, Recharts, React Markdown, Axios |
| Backend | Node.js, Express.js, Mongoose, uuid, dotenv, cors, node-fetch |
| Database | MongoDB (Atlas or local) |
| Primary LLM | Gemini API (`gemini-1.5-flash` + `text-embedding-004`) via `@google/generative-ai` |
| Devil's Advocate LLM | OpenRouter API (`mistralai/mistral-7b-instruct`) via REST fetch |
| Web Search | Serper API (`google.serper.dev`) |

#### [NEW] `backend/src/controllers/session.controller.js`
Thin controller layer — delegates all heavy logic to services. Each function:
1. Extracts params/body
2. Calls one or more services
3. Updates session in DB
4. Returns response / streams SSE

#### [NEW] `backend/src/controllers/report.controller.js`
- `generateReport`: calls `report.service.js`, saves Report doc, updates session.reportId
- `getReport`: fetches Report by reportId

---

#### [NEW] `backend/src/services/gemini.service.js`
Four exported functions using `@google/generative-ai`:
1. `structureIdea(rawIdea)` — JSON mode extraction
2. `generateNextQuestion(unansweredSlot, structuredIdea)` — returns question string
3. `analyzeOneDimension(name, businessProfile, ragContext, webContext)` — JSON mode, returns `{score, reasoning, evidence[]}`
4. `generateReportMarkdown(sessionData)` — returns full markdown string

#### [NEW] `backend/src/services/embedding.service.js`
- `generateEmbedding(text)` — uses `text-embedding-004`, returns 768-dim float array

#### [NEW] `backend/src/services/rag.service.js`
- `retrieveRelevantChunks(query, topK=5)` — embeds query, loads all `knowledge_chunks`, cosine-ranks, filters >0.6, returns top K

#### [NEW] `backend/src/services/webResearch.service.js`
- `searchWeb(query)` — POST to Serper, returns `[{title, url, snippet}]`
- `runResearchQueries(businessProfile)` — runs 3 Serper searches (market size India, competitors India, customer pain points), returns merged array

#### [NEW] `backend/src/services/openrouter.service.js`
- `challengeIdea(businessProfile, feasibilityScore)` — REST POST to OpenRouter, model `mistralai/mistral-7b-instruct`, returns devil's advocate string

#### [NEW] `backend/src/services/analysis.service.js`
- `analyzeAllDimensions(businessProfile, ragResults, webResults)` — calls `analyzeOneDimension` 6 times (sequentially or in parallel), assembles full analysis object, also extracts `risks[]` and `assumptions[]`

#### [NEW] `backend/src/services/scoring.service.js`
- `computeFeasibilityScore(analysis)` — weighted formula: market×0.20 + problem×0.15 + revenue×0.15 + competition×0.15 + founder×0.10 + (100−risk)×0.25

#### [NEW] `backend/src/services/report.service.js`
- `buildReport(session)` — calls `generateReportMarkdown`, generates UUID reportId, returns assembled report object

---

#### [NEW] `backend/src/middleware/errorHandler.js`
- Express 4-arg error handler: `(err, req, res, next)` — returns `{error: err.message}` with appropriate status code.

#### [NEW] `backend/src/utils/cosineSimilarity.js`
- `cosineSimilarity(a, b)` — dot product / (|a| × |b|), handles zero vectors safely.

#### [NEW] `backend/src/utils/chunkText.js`
- `chunkText(text, chunkSize=300, overlap=50)` — word-based sliding window chunking.

#### [NEW] `backend/scripts/ingestKnowledgeBase.js`
Standalone script (run once):

2. Chunks each with `chunkText`
3. Generates embeddings with `embedding.service.js`
4. Upserts docs into `knowledge_chunks` collection (idempotent via chunkId)

## Data Flow (End-to-End)

```
User types idea
    │
    ▼
POST /api/sessions → create session (UUID)
POST /api/sessions/:id/idea → Gemini structures idea, generates Q1
    │
    ▼
[Interview Loop — up to 5 questions]
POST /api/sessions/:id/answer → append answer, get next question
    │
    ▼
GET /api/sessions/:id/research (SSE)
  ├─ RAG: embed query → cosine rank knowledge_chunks → top 5
  └─ Web: 3 Serper searches → merge results
    │
    ▼
POST /api/sessions/:id/analyze
  └─ 6 Gemini calls (one per dimension) → scores + reasoning + evidence
  └─ scoring.service: weighted sum → feasibilityScore
  └─ extract risks[] + assumptions[]
    │
    ▼
POST /api/sessions/:id/challenge
  └─ OpenRouter Mistral → devil's advocate text
    │
    ▼
Results page: RadarChart + EvidencePanel + RiskCards + DevilsAdvocate
    │
    ▼
POST /api/sessions/:id/report
  └─ Gemini → full markdown report
  └─ Save Report doc → return reportId
    │
    ▼
GET /api/reports/:reportId → shareable report page
```

## Open Questions

> [!IMPORTANT]
> **SSE + POST conflict**: `EventSource` in browsers only supports `GET`. The research endpoint is defined as `POST` in the spec but SSE requires `GET`. **Resolution**: The research endpoint will be implemented as `GET /api/sessions/:id/research` with SSE. The frontend opens `new EventSource('/api/sessions/:id/research')`. This matches the routes file above.

> [!NOTE]
> **MongoDB Atlas vs Local**: The `.env.example` will show both options. User should set `MONGODB_URI` before running.

> [!NOTE]
> **Knowledge base ingestion**: Must be run once before starting the backend. The `ingestKnowledgeBase.js` script is idempotent — safe to re-run.
